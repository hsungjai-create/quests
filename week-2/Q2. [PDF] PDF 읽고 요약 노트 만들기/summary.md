## 1. 요약

### 1-1. 3줄 요약

1. 하버스쿨의 'AI 공장장 부트캠프'는 코딩을 직접 배우는 대신 AI(주로 클로드 코드)에게 시켜서, 8주 동안 실제 동작하는 웹앱과 AI 에이전트를 직접 만들고 배포하는 주 1회 라이브 실습 과정이다.
2. 1주차 에이전트 제작 → 프론트엔드 → 백엔드/DB·배포 → 인증·결제/에이전트 팀 → 디자인·최종 발표 순으로 매주 기술 스택을 쌓아가며, 7주차에 실거래 앱 '당근마켓 클론'을, 8주차에 개인 아이디어 v1을 완성·배포한다.
3. 총 161개 학습 유닛(핵심 퀘스트 40개, 튜토리얼 36개, 개념강의 30강, 전담 에이전트 9개 등)으로 구성되어, "무엇을 배웠나"가 아니라 "무엇을 만들었나"로 결과를 증명하는 포트폴리오 중심 커리큘럼이다.

### 1-2. 꼭 알아야 할 핵심 내용 5가지

1. **학습 사이클**: 매주 "개념 강의 → 따라하기 튜토리얼 → 직접 만드는 퀘스트 → 다음 주 복습·퀘스트 리뷰"의 4단계가 반복된다.
2. **8주 로드맵**: 1-2주(에이전트·프론트엔드) → 3-4주(백엔드·DB·배포) → 5-6주(인증·결제·에이전트 팀) → 7-8주(디자인·최종 발표)로, 풀스택 개발과 AI 에이전트 운영 역량을 단계적으로 쌓는 구조다.
3. **다루는 도구·스택**: Claude Code, Agent Skills, Cursor, Git/GitHub, HTML·CSS·JS, React, Node·Express, Supabase, Vercel, TossPayments, ImageKit, Notion MCP, Chrome MCP, GPT Image 2.0, document-skills 등 실무에서 쓰는 도구를 그대로 사용한다.
4. **대표 결과물(Final)**: 7주차에 회원가입·인증·이미지 업로드까지 붙은 실제 동작하는 중고거래 앱 '당근마켓 클론'을 완성하고, 8주차에 본인이 고른 개인 프로젝트(앱 또는 에이전트) v1을 배포·발표하며 수료한다.
5. **운영 방식**: 주 1회 3시간 라이브 실습 × 8주, 기수제 모집(주말반/평일반), 정원이 한정되어 있어 마감 시 다음 기수 대기 신청이 필요하다.

### 1-3. 어려운 용어 풀이

| 용어 | 쉬운 설명 |
|---|---|
| MCP (Model Context Protocol) | AI가 노션·크롬 브라우저 같은 외부 프로그램을 직접 조작할 수 있게 연결해주는 통로. "AI가 실제로 일하게" 만드는 핵심 기술 |
| Agent Skill | 반복되는 업무를 AI에게 "이렇게 처리해"라고 알려주는 재사용 가능한 지침서 묶음 (예: 내 말투로 답장하기, 유튜브 번역) |
| Supabase | 회원 정보·게시글 같은 데이터를 저장하는 데이터베이스를 손쉽게 구축해주는 서비스 |
| Vercel (Agent) | 만든 웹앱을 인터넷에 실제로 올려(배포) 누구나 접속하게 해주는 배포 플랫폼, 여기서는 이 과정을 자동화하는 에이전트 |
| Auth (인증) | 회원가입·로그인·비밀번호 확인 등 "이 사람이 누구인지 확인"하는 시스템 |
| TossPayments | 실제 카드결제 같은 한국형 결제를 앱에 연동할 수 있게 해주는 결제 서비스 |
| 고블린(챌린지) | 정규 커리큘럼 외에 추가로 도전하는 보너스 미션 |
| Single Server Specialist 에이전트 | 백엔드 서버 구축을 전담해서 도와주는 특화 AI 에이전트 |

### 1-4. 내가 바로 할 수 있는 다음 행동 1개

지금 바로 Claude Code(또는 쓰고 있는 AI 코딩 도구)를 열어, 1주차 실습을 그대로 따라 해본다 — **같은 간단한 자기소개 웹페이지를 "채팅으로 만들기 / 에디터(Cursor)로 만들기 / 에이전트(클로드 코드)로 만들기" 세 가지 방식으로 각각 만들어보고 차이를 비교**한다. 이 과정이 실제로 나에게 맞는 학습 방식인지 신청 전에 가늠해볼 수 있는 가장 저비용의 첫걸음이다.

### 1-5. 수료 후 AI Fluency 수준 — Anthropic Academy와 비교

Anthropic Academy의 「AI Fluency: Framework & Foundations」 코스는 **Delegation(위임)·Description(설명)·Discernment(안목)·Diligence(성실성)**, 이른바 4D 프레임워크를 중심으로 AI와 협업하는 사고방식을 익히는 무료 온라인 코스다. 코딩이나 실제 결과물 배포 없이, 글쓰기·리서치 등 범용 업무에 4D를 적용해보는 **개념적·인지적 수준의 fluency**를 목표로 한다.

하버스쿨 부트캠프는 이 4D를 실제 소프트웨어 프로젝트(프론트엔드·백엔드·DB·인증·결제·배포)에 8주간 반복 적용해, 위임한 작업의 결과물(코드·앱·에이전트)이 **실제로 동작하고 인터넷에 배포되는지까지 검증**하는 실행형 과정이다.

- **Delegation·Description**: Anthropic Academy가 텍스트/이미지 업무 단위로 연습한다면, 하버스쿨은 이를 12개 이상의 실무 스택(React, Supabase, TossPayments, MCP 등) 전반에 걸쳐 40개 프로젝트로 반복 훈련한다.
- **Discernment·Diligence**: 하버스쿨에서는 AI가 만든 코드·에이전트가 실제 배포 환경에서 버그·보안·결제 오류 없이 동작하는지까지 검증해야 하므로, 판단 기준이 훨씬 구체적이고 결과가 즉시 드러난다.

**결론**: 두 과정은 공식 등급 체계로 비교되는 인증이 아니므로, 하버스쿨 수료자는 Anthropic Academy AI Fluency 코스가 지향하는 4D 역량을 **개념 이해 단계를 넘어, 소프트웨어 제작이라는 좁지만 깊은 기술 도메인에서 실전으로 검증받은 상태**에 도달한다고 보는 것이 정확하다. 반대로 범용 업무(글쓰기·의사결정·리서치)에 대한 AI 협업 소양은 Anthropic Academy 쪽이 더 넓게 다룬다 — 하버스쿨은 "깊이", Anthropic Academy는 "폭"에 강점이 있는 서로 다른 성격의 fluency다.

*(이 항목은 두 과정의 공개 자료를 바탕으로 한 분석이며, 공식적으로 상호 인증되거나 등급이 매핑된 내용은 아닙니다.)*

## 2. 질문과 답변

### 질문 1. Vercel 관련해서 배워야 하는 내용을 초등학생도 이해할 수 있게 쉽게 설명해주세요.

내가 그림을 그렸어요. 그런데 이 그림은 지금 내 방 책상 위에만 있어서, 나만 볼 수 있어요. 친구들한테 보여주려면 학교 게시판에 붙여야겠죠?

컴퓨터로 앱(웹사이트)을 만드는 것도 똑같아요. 처음 만들면 그 앱은 **내 컴퓨터 안에만** 있어서 나만 볼 수 있어요. 이걸 **"인터넷 게시판"에 붙여서 전 세계 누구나 주소(URL)만 알면 볼 수 있게** 만들어주는 서비스가 바로 **Vercel**이에요. 이렇게 인터넷에 올리는 것을 "배포한다"고 불러요.

**Vercel Agent**는 게시판에 그림을 붙이는 순서(핀 꽂는 자리 찾기, 이름표 붙이기 등)를 대신 다 알아서 해주는 **AI 심부름꾼**이에요.

또 하나, **환경변수**는 내 그림 뒷면에 몰래 적어둔 "우리 집 비밀번호" 같은 걸, 게시판에 붙일 때는 안 보이게 따로 봉투에 넣어서 관리하는 것과 같아요. 앱의 "비밀 정보"(로그인 비밀번호, 결제 열쇠 등)를 코드에 직접 쓰지 않고 따로 안전하게 보관하는 방법이에요.

> **근거**
> - 4페이지 (Week 04 "데이터베이스 & 배포"): "DB(Supabase)를 붙여 데이터가 남는 앱을 만들고... **Vercel Agent로 인터넷에 실제 배포합니다**" / "무엇을 배우나" 항목의 "배포 · 환경변수 · **Vercel Agent**"
> - 7페이지 (8주 동안 다루는 도구·스택 목록): 도구 태그 "**Vercel**"

### 질문 2. Supabase 관련해서 배워야 하는 내용을 초등학생도 이해할 수 있게 쉽게 설명해주세요.

화이트보드에 오늘 할 일을 적었어요. 그런데 컴퓨터를 끄면(=앱을 닫으면) 화이트보드 글씨가 싹 지워져 버려요. 다시 켜면 어제 적은 건 하나도 안 남아 있죠.

**Supabase는 지워지지 않는 마법의 일기장** 같은 거예요. 앱에 적은 내용(친구 이름, 할 일 목록, 게시판 글 등)을 여기에 저장해두면, 컴퓨터를 껐다 켜도 **그대로 남아 있어요**. 이렇게 "내용을 계속 기억해주는 커다란 창고"를 "데이터베이스(DB)"라고 부르고, Supabase는 그 창고를 쉽게 만들어주는 서비스예요.

내 방에 장난감 상자(=Supabase 창고)가 하나 있다고 생각해보면, **나(=앱)도 이 상자를 열어서 장난감을 넣었다 뺐다** 할 수 있고, **내 로봇 친구(=AI 에이전트)도 똑같은 상자를 열어서** 정리하거나 꺼내줄 수 있어요. 그래서 내가 가계부 앱에 오늘 쓴 돈을 적어두면, AI 에이전트가 그 상자를 열어서 "이번 달 너무 많이 썼어!"라고 분석해줄 수 있는 거예요.

> **근거**
> - 4페이지 (Week 04 "데이터베이스 & 배포"): "**DB(Supabase)**를 붙여 **데이터가 남는 앱**을 만들고, 같은 데이터를 앱과 에이전트 양쪽으로 조작해봅니다" / "무엇을 배우나" 항목의 "**데이터베이스 개념 · Supabase**", "내 데이터를 앱·에이전트로 조작하기" / "무엇을 만드나" 항목의 "냉장고 레시피 스킬 + AI 레시피 앱", "실시간 밸런스 게임 · 익명 연봉·지출 비교", "익명 고민·칭찬 게시판 · **To-Do(DB)**"
> - 7페이지 (8주 동안 다루는 도구·스택 목록): 도구 태그 "**Supabase**"

### 질문 3. 이 과정 수료 후 나의 스킬이 어디까지, 무엇을 할 수 있어야 되는지 초등학생도 이해하게 쉽게 설명해주세요.

**1. 컴퓨터한테 "말"로 시켜서 진짜로 쓰는 웹사이트를 만들 수 있어요**
그림책만 보는 게 아니라, 직접 로봇 조수(AI)한테 "이런 걸 만들어줘"라고 말해서 실제로 인터넷에 올라가는 앱을 40번 넘게 만들어봐요.

**2. 회원가입도 되고, 물건도 사고팔 수 있는 "진짜 당근마켓" 같은 앱을 완성해요**
로그인하고, 사진도 올리고, 물건을 사고파는 앱 — 장난감 가게 놀이가 아니라 **진짜로 작동하는** 앱을 완성해요.

**3. 돈을 실제로 받을 수 있는 가게(쇼핑몰)도 만들어요**
용돈 계산 놀이가 아니라, 진짜 카드 결제가 되는 온라인 가게를 만들어봐요.

**4. 나만의 로봇 심부름꾼(AI 에이전트)을 직접 만들 수 있어요**
"내 말투로 답장해줘", "유튜브 영상 번역해줘"처럼, 귀찮은 일을 대신 해주는 나만의 로봇 심부름꾼을 직접 만들어요.

**5. 내가 만든 걸 예쁘게 꾸며서, 인터넷에 올리고, 사람들 앞에서 발표해요**
숙제를 서랍 속에 넣어두는 게 아니라, 세상 누구나 볼 수 있게 인터넷에 올리고(배포), 친구들 앞에서 발표까지 해서 **수료증**을 받아요.

**한 문장으로**: 8주 뒤에는 "AI한테 시켜서 상상한 걸 진짜로 만들고, 인터넷에 올려서 남들도 쓰게 만들고, 발표까지 하는 사람"이 되는 거예요.

> **근거**
> - 1페이지: "8주 라이브 실습 과정", "40개 직접 만드는 퀘스트", "10개 나만의 에이전트·스킬", "161 총 학습 유닛"
> - 2페이지: "강의를 듣는 게 아니라, **앱과 에이전트를 만들어 배포하고 끝납니다**" / "'무엇을 배웠다'가 아니라 '**무엇을 만들었다**'로 끝나는 과정" + 결과물 목록(당근마켓 클론, AI 쇼핑몰, 가계부+분석 에이전트, 나만의 Agent Skill 3종, 개인 프로젝트 v1→배포)
> - 6페이지: "당근마켓 클론 (Final)", "개인 프로젝트 v1 완성 → 배포 (Final)", "발표 → 수료증"
> - 7페이지: "이 과정은 듣기보다 **만들기가 압도적으로 많습니다**"
