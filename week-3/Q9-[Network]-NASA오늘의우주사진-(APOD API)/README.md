# 🌌 오늘의 우주 사진 (NASA APOD 매거진)

NASA의 "오늘의 천문학 사진(Astronomy Picture of the Day, APOD)" API를 활용해
매일 선정되는 우주 사진(또는 영상)과 전문가의 설명을 잡지(매거진) 스타일 페이지로
보여주는 단일 페이지 웹앱입니다. 별도 백엔드 없이 정적 파일만으로 동작하며,
GitHub Pages에 그대로 배포할 수 있습니다.

## 실행 방법

1. 이 폴더의 `index.html`을 브라우저로 엽니다. (API 키 없이도 공용 `DEMO_KEY`로 바로 동작합니다)
2. 화면 상단 ⚙️ 버튼을 눌러 본인의 NASA API 키를 등록하면 요청 제한 없이 편하게 사용할 수 있습니다.

### GitHub Pages로 배포

1. 이 폴더를 별도 저장소(public repo)에 push 합니다.
2. 저장소 설정 → Pages에서 배포 브랜치/폴더를 지정합니다.
3. 배포된 URL로 접속하면 동일하게 동작합니다.

## API 키 설정 방법 (별도 삽입)

이 앱은 **API 키를 코드/저장소에 저장하지 않습니다.** 대신 화면의 설정 패널을 통해
사용자가 직접 입력한 키를 브라우저의 `localStorage`에만 저장합니다.

1. 화면 우측 상단의 ⚙️ 버튼 클릭
2. 입력창에 본인의 NASA API 키를 붙여넣고 "저장" 클릭
3. 키는 이 브라우저에만 저장되며, GitHub에 올라가는 파일에는 절대 포함되지 않습니다
4. 키를 등록하지 않아도 앱은 정상 동작합니다 (공용 `DEMO_KEY` 사용, 다만 시간당 요청 횟수 제한이 낮아 자주 끊길 수 있음)

키가 없다면 [api.nasa.gov](https://api.nasa.gov/)에서 이메일 주소만으로 무료로 즉시 발급받을 수 있습니다.

> ⚠️ NASA API 키처럼 무료로 재발급 가능한 키라도, 코드에 하드코딩하면 GitHub에 올라간 뒤
> 봇들이 공개 저장소를 스캔해 몇 분 안에 수집해 갈 수 있습니다. 그래서 이 프로젝트는
> 항상 "설정 패널 + localStorage" 방식으로 키를 분리해 관리합니다.

## 사용한 API

- [NASA APOD API](https://api.nasa.gov/) — `GET /planetary/apod`
  - 파라미터: `api_key`, `date` (YYYY-MM-DD)
  - 응답 필드: `title`, `date`, `explanation`, `url`/`hdurl`, `media_type`, `copyright` 등

## 주요 기능

- 오늘 날짜의 NASA 우주 사진과 전문가 설명을 잡지 스타일(대형 헤드라인, 드롭캡, 컬럼 타이포그래피)로 표시
- 상단 날짜 선택기로 과거 특정 날짜의 APOD도 조회 가능 (서비스 시작일 1995-06-16부터)
- 사진뿐 아니라 영상(`media_type: "video"`)이 선정된 날은 자동으로 임베드 플레이어로 표시
- 고화질 원본 이미지 링크 및 NASA 원문 페이지 링크 제공
- ⚙️ 설정 패널을 통한 API 키 등록/삭제 (localStorage 저장, 코드에는 미포함)
- 키 미등록 시 공용 `DEMO_KEY`로 자동 폴백 + 안내 배지 표시
- 로딩 중 스켈레톤 UI, API 오류(401/403/429 등) 시 원인별 안내 카드 + 에러 토스트

## 파일 구조

```
├── index.html   # 페이지 마크업 (매거진 레이아웃 + API 키 설정 모달)
├── style.css    # 매거진(잡지) 스타일 - 세리프 타이포그래피, 드롭캡, 다크 마스트헤드
├── script.js    # API 호출, 날짜 처리, 렌더링, localStorage 키 관리
└── screenshots/ # 스크린샷 저장 폴더
```
