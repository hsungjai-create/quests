# 장보기 리스트

혼밥 덮밥/국밥 3종(참치마요덮밥, 소불고기덮밥, 콩나물국밥)을 위한 장보기 리스트입니다.
재료 낭비를 줄이기 위해 최소 구매 단위 기준으로 작성했습니다.

## 전체 장보기 리스트 (최소 구매 단위 기준)

### 신선/냉장 식품

| 품목 | 최소 구매 단위 | 비고 |
|---|---|---|
| 계란 | 6구입 1팩 | 3개 레시피에서 최대 3개 사용 |
| 대파 | 1대 (또는 쪽파 1봉지) | 3개 레시피 공통, 소량씩만 사용 |
| 양파 | 1개 | 소불고기용, 남으면 다른 요리에 활용 |
| 당근 | 1개 (선택) | 소불고기 고명용, 없어도 무방 |
| 마늘 | 다진마늘 소포장 1개 (또는 통마늘 1망) | 소불고기 + 콩나물국밥 공통 |
| 소고기 (불고기용) | 100~150g | 정육점에서 소분 구매 추천 (마트는 보통 300g가 최소단위) |
| 콩나물 | 1봉지 (200~300g, 최소포장) | 100g만 쓰고 남은 건 무침용으로 활용 가능 |

### 통조림

| 품목 | 최소 구매 단위 | 비고 |
|---|---|---|
| 참치캔 | 소(100g) 1개 | 참치마요덮밥 전량 사용 |

### 조미료/양념 (기본 상비 조미료, 없는 것만 구매)

| 품목 | 최소 구매 단위 | 비고 |
|---|---|---|
| 마요네즈 | 1병 (소용량 추천) | 참치마요덮밥용 |
| 양조간장 | 1병 | 참치마요 + 소불고기 공통 |
| 국간장 | 1병 | 콩나물국밥 전용 (양조간장과 다름, 대체 불가) |
| 새우젓 | 소포장 1개 | 콩나물국밥 간 맞춤용 |
| 설탕 | 소포장 | 참치마요 + 소불고기 |
| 참기름 | 1병 (소용량) | 3개 레시피 공통 |
| 맛술(미림) | 1병 (소용량) | 소불고기용 |
| 통깨 | 소포장 1개 | 참치마요 + 소불고기 |
| 고춧가루 | 소포장 (선택) | 콩나물국밥 매콤하게 먹을 경우 |
| 후추 | 이미 있으면 생략 | 소불고기용 |
| 멸치육수팩 | 1봉지 (또는 멸치+다시마 소포장) | 콩나물국밥 육수용, 시판 육수팩도 가능 |
| 즉석밥 | 3개입 | 3끼 분량 정확히 맞춤 |

## 남는 재료 활용 팁

- **소고기**: 150g만 쓰고 남으면 소분해 냉동 보관 → 다음에 볶음밥이나 국거리로 활용
- **콩나물**: 100g만 쓰고 남으면 소금간 콩나물무침으로 바로 활용 가능
- **대파/양파**: 남은 자투리는 잘게 썰어 냉동 보관하면 국물요리에 바로 투입 가능
- **계란**: 6구 중 3개 사용, 남은 3개는 다른 아침 식사용으로 활용
